# 模擬可疑特店通報地圖

一個純前端、在本機執行的網頁，將 `data/suspicuous_shops_data.csv` 中 612 筆
**模擬** 可疑特店通報，標示在台灣地圖上。

> **模擬資料**：本專案所有通報與特店資料皆為模擬產生，並非真實案件，不得作為任何
> 判斷或指控的依據。

## 執行方式

從乾淨的 clone 開始，只需要兩個指令，不需要任何額外設定、金鑰或帳號：

```bash
npm install
npm run dev
```

Vite 會印出本機網址（預設 <http://localhost:5173/>），在瀏覽器開啟即可。

## 其他指令

| 指令 | 用途 |
|---|---|
| `npm test` | 執行 Vitest 測試（CI 的必要檢查） |
| `npm run build` | TypeScript 型別檢查 |
| `npm run generate:coordinates` | 重新產生座標對照檔，**僅在地址資料變動時手動執行** |

## 位置的來源與限制

- 座標來自已納入版控的對照檔 `src/data/address-coordinates.json`。
  執行中的網頁 **不會** 呼叫任何地址轉座標（geocoding）服務。
- 對照檔以道路層級的錨點加上決定性偏移產生，因此圖上的位置是
  **道路層級的近似位置**，並非確切門牌或建築物座標。
- 同一個完整地址的多家特店會落在同一個點，並以不同樣式標示為「共用地址」；
  同一條路上的不同地址則各自是獨立的標記。
- 地圖圖磚由 OpenStreetMap 提供，於執行時載入。圖磚無法載入時，
  標記、標題列與各項說明仍會正常顯示。
